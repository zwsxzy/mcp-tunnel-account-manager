Codex 桥接

tunnel-client 在子进程 PATH 中发现 codex 时，会自动拉起 codex app-server 作为桥接。 每份约占用 96 MB 内存，并会弹出控制台窗口。关闭后启动的隧道将从 PATH 中移除 npm 目录， 不再拉起该桥接。MCP 工具调用不受影响。
