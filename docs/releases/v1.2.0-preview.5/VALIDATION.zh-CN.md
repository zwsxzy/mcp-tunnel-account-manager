## 本次修复的验证证据

| 缺陷 | 复现 | 修复后 |
| --- | --- | --- |
| HTTP 隧道回滚后无法启动 | 真实运行时状态中 `record.operationId` 为 `<opId>-restored`，而 `packet.operationId` 为原 op；用前者解封必抛 `INVALID_HTTP_STATE` | 以包内 `operationId` 解封成功；实机在三目标切换中返回 `SUCCEEDED`，桥接隧道进程正常运行 |
| 服务无法移除 | `rt?.state` 恒为 `undefined` → 状态恒为 `unknown` → 恒返回 `RUNTIME_STATE_UNKNOWN` | 三个服务均正确解析为 `stopped` 并允许移除；运行中仍返回 `MCP_RUNNING` |
| 拒绝原因不可见 | 界面只显示 `REJECTED` | 显示真实错误码（如 `INVALID_HTTP_STATE`） |
